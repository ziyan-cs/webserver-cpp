# TCP Connection

## 目标

实现 TCP 地址、socket、连接接受和连接读写的基础封装，并将连接接入事件循环。

## 结果

- 建立 `InetAddress`、`Socket`、`Acceptor`、`TcpConnection` 和 `TcpServer` 的初版。
- 建立输入、输出 Buffer 和事件回调；网络连接专项测试与 Echo 流程尚未完成。
- 此前 Debug 构建和已有测试通过，但这些测试尚未覆盖 TCP 收发。

## 关键问题

### 非阻塞读写与部分发送

**现象**：`EAGAIN` 不代表连接失败；一次写入也不保证发送完全部数据。

**处理**：`EINTR` 时重试，`EAGAIN` 时等待下次就绪；未发送数据保留在输出 Buffer 中，清空后关闭写事件关注。读到 EOF 时处理连接关闭。

### 回调期间删除连接

**风险**：关闭回调中立即删除连接，仍在执行的事件分发可能访问已销毁对象。

**处理**：TcpServer 暂存待删除连接，在本轮事件分发结束后清理对象。

**限制**：当前 socket 在延迟删除前关闭，fd 复用及旧事件误分发的问题尚未解决。

### fd 所有权

**问题**：接受连接后用裸 fd 跨回调传递，所有权不清晰。

**处理**：Acceptor 通过 `unique_ptr<Socket>` 转交所有权；未设置回调时由局部对象释放。

**限制**：接受 fd 后、分配 Socket 成功前发生异常时，资源管理仍需完善。

## 设计决定

- 输入 Buffer 暂存收到的数据；输出 Buffer 暂存等待发送的数据，两者由连接和上层逻辑协调。
- 单个连接发生读写错误时记录并关闭连接；初始化等无法完成的操作向调用者报告异常。
